Класс: StringUtils
Назначение: Утилиты для обработки строк
Тестировщик: Екатерина

Заголовок: Отсутствие обработки None в методах.

Серьезность: КРИТИЧЕСКИЙ
Приоритет: ВЫСОКИЙ

Описание:
Все методы класса не обрабатывают передачу значения None в качестве параметра,
что приводит к возникновению исключений AttributeError

Шаги для воспроизведения:
1. Создать экземпляр StringUtils
2. Вызвать любой метод с первым параметром None - Пример: string_utils.delete_symbol(None, "a")
3. Наблюдать исключение AttributeError

Ожидаемый результат:
Метод должен либо обработать None (вернуть None или пустую строку),
либо явно указать в документации, что None не поддерживается.

Фактический результат:
 AttributeError: 'NoneType' object has no attribute 'index'

 Окружение: Python 3.8+
